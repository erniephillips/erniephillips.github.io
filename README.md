# EPATA LLC Site

Static GitHub Pages site for EPATA LLC, a New Jersey-based 3D printing, CAD cleanup, functional prototyping, custom website, and AI workflow business.

The site is built as a fast one-page business presence with:

- 3D printing and CAD service positioning
- Fusion 360 and design-to-print workflow language
- Custom websites and AI-assisted 3D printing workflow services
- MakerWorld and Etsy marketplace product positioning
- Project quote intake guidance
- Business-facing fabrication credibility
- Clean contact paths for EPATA LLC

The previous portfolio/bio homepage is preserved in trimmed form at `bio.html` with archived `css/bio-main.css` and `js/bio-main.js` files so it can remain available without changing the EPATA homepage.
